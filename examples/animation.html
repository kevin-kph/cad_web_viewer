Instructions: Create keyframes at different times using the controls at the top right then play them back as an animation. For example, click a node with the time at the upper right set to 0. Then press "Keyframe Node" with the node you want to keyframe selected. Then move the time forward, reselect and translate the node with the handles, and keyframe it again. Press the play button and you should see the node move between the two locations you provided.

You can also keyframe color, opacity, and visibility state so long as their checkboxes are checked. To change the color of a node, set the color you want to use in the color selector, then select the node whose color you want to set and press the "Set Node Color" button. A similar process can be followed for opacity.

You can also import and export your animations. To demonstrate: create an animation then press the "Export JSON" button. Copy the resulting text from the text box below the button. Delete your animation or refresh the page. You can paste your JSON into the input textbox and press "Import JSON" to import the animation.
